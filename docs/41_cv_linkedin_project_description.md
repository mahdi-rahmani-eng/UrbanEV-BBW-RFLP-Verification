## CV Title

## Short CV Description

Developed a concept-level model-based validation workflow for low-speed urban electric vehicle brake-request logic using MATLAB/Simulink, Stateflow, scenario-based validation, requirement-test-result evidence, ODD coverage, regression planning, and structured technical documentation.

## CV Bullet Points

- Built a MATLAB/Simulink validation workflow for simplified low-speed urban EV brake-request logic based on stopping-distance and time-to-collision estimation.
- Implemented a Stateflow finite-state warning logic with SAFE, CAUTION, WARNING, and EMERGENCY_BRAKE states.
- Compared Stateflow outputs against the original Simulink decision logic for warning-state and brake_request validation.
- Organized validation evidence using requirement-test-result mapping, scenario documentation, and structured evidence summaries.
- Defined conceptual automotive signal interfaces and CAN-style signal mapping for portfolio-level automotive communication discussion.
- Created extended ODD scenarios, ODD coverage summaries, and regression test planning to support repeatable validation thinking.
- Added repository-level documentation, reviewer guides, demo walkthrough material, and artifact integrity checks for GitHub portfolio readiness.

## LinkedIn About-Style Project Summary

The goal was not to build a production brake-by-wire system, but to demonstrate an organized automotive validation mindset, including traceability, evidence management, interface thinking, and scope-safe technical documentation.
